# Project: NEXUS-6 Ω (Unified AGI System)

## Overview
NEXUS-6 Ω is a sophisticated, modular swarm intelligence platform designed for autonomous inference, self-evolution, and secure cognitive operations. It utilizes a decentralized "Hive Kernel" to orchestrate multiple agents across a deep cognitive stack.

## Architecture
- **Hive Kernel**: The orchestration layer managing agent lifecycles and global state.
- **Deep Cognitive Stack**: Handles inference and memory persistence.
- **Mythos Guard**: Security layer providing formal verification and integrity checks.
- **Cyberpunk Dashboard**: Real-time monitoring interface built with Streamlit.

## Setup
```bash
pip install streamlit
export PYTHONPATH=$PYTHONPATH:.
streamlit run agi_unified_system.py
```
